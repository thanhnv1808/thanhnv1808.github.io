Welcome to the complete study guide for the **AWS Certified AI Practitioner (AIF-C01)** certification. This series covers all domains and knowledge areas you need to pass the exam.

## Exam Overview

| Detail | Information |
|--------|-------------|
| **Exam Code** | AIF-C01 |
| **Level** | Foundational |
| **Pass Score** | 700/1000 (scaled score) |
| **Total Questions** | 65 (50 scored + 15 unscored) |
| **Time** | 90 minutes |
| **Cost** | $100 USD |

## Exam Domains

| Domain | Weight | Focus Areas |
|--------|--------|-------------|
| **Domain 1** | 20% | Fundamentals of AI and ML |
| **Domain 2** | 24% | Fundamentals of Generative AI |
| **Domain 3** | 28% | Applications of Foundation Models |
| **Domain 4** | 14% | Guidelines for Responsible AI |
| **Domain 5** | 14% | Security, Compliance, and Governance |

## Question Types

The exam includes four types of questions:

1. **Multiple Choice** - Select 1 correct answer from 4 options
2. **Multiple Response** - Select 2+ correct answers from 5+ options
3. **Ordering** - Arrange 3-5 responses in correct sequence
4. **Matching** - Match responses to prompts (3-7 pairs)

> **Tip**: There is no penalty for guessing. Never leave a question unanswered!
{: .prompt-tip }

## Target Candidate Profile

This exam is designed for candidates with:
- Up to 6 months of exposure to AI/ML technologies on AWS
- Understanding of core AWS services (EC2, S3, Lambda, IAM)
- Familiarity with AI/ML concepts and terminology

### What You DON'T Need

You are **NOT** expected to:
- Write code or develop ML models
- Perform data engineering or feature engineering
- Tune hyperparameters or optimize models
- Build ML pipelines or infrastructure
- Perform mathematical/statistical analysis

> **Note**: This is a foundational exam focused on understanding concepts, not implementation.
{: .prompt-info }

## Exam Tips

### Before the Exam
- Review all AWS AI/ML service documentation
- Take practice exams
- Focus on understanding use cases, not implementation details
- Know the differences between services

### During the Exam
- Read questions carefully - look for keywords
- Eliminate obviously wrong answers first
- Don't spend too much time on one question
- Flag and return to difficult questions
- Answer ALL questions (no penalty for guessing)

### Key Concepts to Master
1. **AI vs ML vs Deep Learning vs GenAI** - Know the differences
2. **Supervised vs Unsupervised vs Reinforcement Learning** - When to use each
3. **Foundation Models** - What they are and how to use them
4. **RAG (Retrieval Augmented Generation)** - Architecture and benefits
5. **Prompt Engineering** - Techniques and best practices
6. **Responsible AI** - Bias, fairness, explainability
7. **AWS Shared Responsibility Model** - Who is responsible for what
